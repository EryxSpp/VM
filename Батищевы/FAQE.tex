\title{Font Awesome Quarto Extension}
\author{}
\date{}
\begin{document}
\maketitle


This extension allows you to use font-awesome icons in your Quarto HTML
and PDF documents. It provides an
\texttt{\{\{\textless{}\ fa\ \textgreater{}\}\}} shortcode:

\begin{itemize}
\item
  Mandatory \texttt{\textless{}icon-name\textgreater{}}:

\begin{Shaded}
\begin{Highlighting}[]
\NormalTok{\{\{\textless{} fa }\DataTypeTok{\textless{}}\KeywordTok{icon{-}name}\DataTypeTok{\textgreater{}}\NormalTok{ \textgreater{}\}\}}
\end{Highlighting}
\end{Shaded}
\item
  Optional \texttt{\textless{}group\textgreater{}},
  \texttt{\textless{}size=...\textgreater{}},
  \texttt{\textless{}title=...\textgreater{}} and
  \texttt{\textless{}label\ =\ ...\textgreater{}}:

\begin{Shaded}
\begin{Highlighting}[]
\NormalTok{\{\{\textless{} fa }\DataTypeTok{\textless{}}\KeywordTok{group}\DataTypeTok{\textgreater{}} \DataTypeTok{\textless{}}\KeywordTok{icon{-}name}\DataTypeTok{\textgreater{}}\NormalTok{ \textless{}size=...\textgreater{} \textless{}title=...\textgreater{} \textless{}label=...\textgreater{}\}\}}
\end{Highlighting}
\end{Shaded}

  \begin{itemize}
  \tightlist
  \item
    \texttt{group} defaults to \texttt{solid}.
  \item
    \texttt{size} usage is detailed in
    \url{https://github.com/quarto-ext/fontawesome\#sizing-icons}
  \item
    \texttt{title} is used only in HTML format to set the
    \href{https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/title}{\texttt{title}
    attribute} on the \texttt{\textless{}i\textgreater{}} element.
  \item
    \texttt{label} is used only in HTML format to set
    \texttt{aria-label} attribute. If unset, the \texttt{icon-name} is
    used.
  \end{itemize}
\end{itemize}

Note that the icon sets are currently not perfectly interchangeable
across formats:

\begin{itemize}
\tightlist
\item
  \texttt{html} uses FontAwesome 6.7.2 from
  \textless{}\url{https://github.com/FortAwesome/Font-Awesome}
\item
  \texttt{pdf} uses the
  \href{https://ctan.org/pkg/fontawesome6}{\texttt{fontawesome6}}
  package, based on FontAwesome 6.7.2 too.
\item
  Other formats are currently not supported, but PRs are always welcome!
\end{itemize}

\textbf{Usage tips:}

\begin{itemize}
\tightlist
\item
  Most icons work without a group prefix:
  \texttt{\{\{\textless{}\ fa\ icon-name\ \textgreater{}\}\}}
\item
  Brand icons require the \texttt{brands} group:
  \texttt{\{\{\textless{}\ fa\ brands\ icon-name\ \textgreater{}\}\}}
\item
  Regular icons can use the \texttt{regular} group:
  \texttt{\{\{\textless{}\ fa\ regular\ icon-name\ \textgreater{}\}\}}
\item
  Solid icons (default) can optionally use \texttt{solid} group:
  \texttt{\{\{\textless{}\ fa\ solid\ icon-name\ \textgreater{}\}\}}
\end{itemize}
